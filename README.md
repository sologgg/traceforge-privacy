# TraceForge

A local-only debugging toolkit for web developers, as a Chrome extension.

- **Capture & Replay**: record your tab's HTTP requests, edit them and send them again, or copy them as cURL
- **Rookie Mode**: turns captured requests into readable actions like "Update profile"
- **Cookie Manager**: save cookie profiles and switch between test accounts
- **Page Helper**: inspect localStorage, sessionStorage, forms and scripts

TraceForge asks for access one site at a time, and all data stays on your device. No analytics, no tracking, no servers.

**Privacy policy:** https://sologgg.github.io/traceforge-privacy/

**Bugs or questions:** [open an issue](https://github.com/sologgg/traceforge-privacy/issues)

Only use TraceForge on websites and accounts you own or are authorized to test.
